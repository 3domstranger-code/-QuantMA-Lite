# Руководство пользователя CodeAgent

## Что такое CodeAgent?

CodeAgent — это ИИ-помощник, который работает **полностью на вашем телефоне**. Он использует локальную языковую модель (llama.cpp) для помощи с кодом, ответов на вопросы и консультаций — без отправки данных на внешние серверы.

**Два режима:**
- **Режим чата** — универсальный ИИ-помощник для вопросов, советов, обучения, объяснения кода, перевода и повседневных задач. Быстрый и простой.
- **Режим агента** — автономный агент для программирования: читает, пишет и редактирует файлы, управляет git-репозиториями и проверяет качество кода.

---

## Начало работы

### Первый запуск

1. **Скачайте модель** — при первом запуске вам будет предложено скачать ИИ-модель из каталога. Выберите модель под ваши задачи:

   **Для общения и советов (Режим чата):**
   - **Qwen2.5 3B** (~2 ГБ, 4 ГБ+ RAM) — компактная, мультиязычная, быстрая
   - **Qwen2.5 7B** (~4.7 ГБ, 6 ГБ+ RAM) — лучший чат для флагманов
   - **Phi-3.5 Mini** (~2.2 ГБ, 4 ГБ+ RAM) — быстрая и умная от Microsoft

   **Для кода и агента (Режим агента):**
   - **Qwen2.5-Coder 3B** (~2.1 ГБ, 4 ГБ+ RAM) — лучший компактный кодер
   - **Qwen2.5-Coder 7B** (~4.7 ГБ, 6 ГБ+ RAM) — рекомендуется для большинства
   - **Qwen2.5-Coder 14B** (~9 ГБ, 12 ГБ+ RAM) — уровень GPT-4o, только флагманы

   **Для работы с изображениями (мультимодальные):**
   - **Qwen3-VL 2B** (~1.8 ГБ + vision) — скриншоты, макеты UI, фото ошибок
   - **Qwen3-VL 4B** (~2.9 ГБ + vision) — таблицы, графики, OCR, видео

   Каталог показывает подробные характеристики и возможности перед загрузкой, с кнопками Скачать/Отмена.

2. **Предоставьте разрешение на доступ к хранилищу** — CodeAgent необходим доступ к вашим файлам для просмотра и редактирования кода.

3. **Укажите рабочую директорию** — перейдите в Настройки и задайте папку, в которой находятся ваши проекты.

### Навигация

В приложении 3 основные вкладки:
- **Чат** — общение с ИИ-агентом
- **Файлы** — просмотр и редактирование файлов
- **Настройки** — конфигурация агента, моделей, git и внешнего вида

## Режим чата: ИИ-помощник

В режиме чата (по умолчанию) CodeAgent работает как быстрый универсальный ИИ-помощник. Без доступа к файлам — только разговор.

**Что можно делать:**
- Задавать вопросы о коде, программировании и архитектуре
- Получать советы, объяснения и помощь в обучении
- Переводить тексты между языками
- Генерировать идеи, писать черновики, подводить итоги
- Обсуждать что угодно — модель работает локально и приватно

**Переключение режимов:** нажмите иконку робота в верхней панели для переключения между Режимом чата и Режимом агента. Если вы запросите файловые/git операции в Режиме чата, вам предложат переключиться.

**Автоопределение формата промпта:** приложение автоматически определяет тип модели (Qwen, Llama 3, CodeLlama, Phi, DeepSeek и др.) и применяет правильный шаблон промпта. Никакой ручной настройки не нужно.

## Режим агента: автономное программирование

Агент работает на базе **SAS (Secure Agent Shell) v3.2** — изолированного движка с **26 инструментами**, детекцией намерений и двумя режимами выполнения.

### Как работает агент

Когда вы отправляете сообщение в Режиме агента, агент запускает **цикл «думай — действуй — наблюдай»**:

1. **Думай** — ИИ анализирует ваш запрос и определяет намерение (одна из 14 категорий)
2. **Действуй** — выполняет инструмент (чтение файла, запись файла, поиск, git-команда и т.д.)
3. **Наблюдай** — видит результат и решает, что делать дальше
4. Повторяет до завершения задачи (по умолчанию до 15 итераций)

### Два режима выполнения

| Режим | Для моделей | Как работает |
|-------|------------|-------------|
| **Стандартный** | Мощные (14B+, Qwen 32B+) | Полный цикл агента — LLM планирует автономно |
| **Управляемый (Guided)** | Маленькие (7B, 3B) | TaskPlanner разбивает запрос на микрошаги, каждый с узким промптом для одного инструмента |

Guided Mode активируется автоматически по размеру модели. Планировщик определяет намерение и генерирует пошаговый план — даже маленькие модели могут выполнять сложные задачи вроде «создай файл и закоммить его».

### Что можно попросить

#### Операции с файлами (6 инструментов)
- «Прочитай src/Main.kt» — чтение с опциональным смещением/лимитом
- «Создай новый файл Utils.kt с функцией formatDate»
- «Удали старый тестовый файл» — перемещает в `.sas_trash/`, не удаляет навсегда
- «Покажи все файлы в директории src» — доступен рекурсивный режим
- «Добавь обработку ошибок в функцию processData в DataManager.kt»
- «Добавь заголовок лицензии во все исходники»

#### Анализ кода (2 инструмента)
- «Найди все комментарии TODO в проекте» — группировка по тегам (TODO/FIXME/HACK/XXX)
- «Сколько строк кода в src/?» — разбивка: всего, код, пустые, комментарии
- «Найди все использования fetchData» — regex-поиск по проекту

#### Рефакторинг
- «Отрефактори класс UserService для использования корутин»
- «Переименуй функцию getData в fetchUserData»
- «Вынеси логику валидации в отдельную функцию»

#### Git-операции (13 инструментов)
- «Покажи git status» / «Покажи подробный git status» — staged/modified/untracked + опережение/отставание
- «Закоммить все изменения» / «Автокоммит» — автоматическая генерация сообщения из diff
- «Создай новую ветку feature/auth»
- «Переключись на ветку main» / «Checkout develop»
- «Запуш изменения на удалённый» — безопасный push, блокирует если behind
- «Покажи историю коммитов» — с опциональным фильтром по файлу
- «Застэшь текущие изменения» / «Достань из стэша» / «Покажи список стэшей»
- «Смерджи feature/auth в main» / «Удали ветку old-feature»

#### Качество кода (4 инструмента)
- «Проверь этот файл линтером» — trailing whitespace, длина строк, именование, пустые catch, wildcard imports
- «Отформатируй Main.kt» — авто-исправление отступов, line endings, EOF newline (показывает diff-preview)
- «Посчитай строки кода в проекте»
- «Найди все TODO в проекте»

#### Составные операции
- «Создай Utils.kt и закоммить» — агент создаёт файл, линтит, стейджит и коммитит за один проход
- «Проверь Main.kt» — read-only анализ: чтение + lint + подсчёт строк + поиск TODO + резюме от LLM

### Система подтверждений

Когда агент собирается выполнить **деструктивную операцию**, он сначала запросит ваше подтверждение:

**Операции, требующие подтверждения:**
- Запись/создание/дополнение файлов
- Удаление файлов (мягкое удаление в `.sas_trash/`)
- Форматирование файлов
- Git: add, commit, push, создание/удаление ветки, checkout, merge

Вы увидите предварительный просмотр изменений (diff для редактирования файлов) и сможете **Подтвердить** или **Отклонить** действие.

### Безопасность

Агент работает в **изолированной среде (sandbox)**:
- Все пути заблокированы в рабочей директории — побег невозможен
- Path traversal (`..`) и символические ссылки блокируются
- Записывать можно только файлы с разрешёнными расширениями (~30 типов)
- Системные директории (`/system`, `/proc`, `/dev` и т.д.) заблокированы
- Код валидируется перед записью: проверка скобок, строковых литералов, потери контента, сканирование опасных паттернов (`eval`, `exec`, `subprocess`)
- Rate limiting: максимум 60 операций в минуту
- Удалённые файлы попадают в `.sas_trash/`, не удаляются навсегда

### Навыки (умные команды)

Агент автоматически распознаёт определённые намерения и активирует специализированные навыки:

| Что вы говорите | Активируемый навык |
|---|---|
| "Explain this code" / "Объясни код" | Объяснение кода — читает файл и даёт подробный разбор |
| "Refactor..." / "Отрефактори..." | Рефакторинг — анализирует, предлагает план, затем вносит изменения |
| "Write tests" / "Напиши тесты" | Генерация тестов — читает исходный код, создаёт тестовый класс |
| "Commit" / "Закоммить" | Git commit — проверяет статус, добавляет файлы, коммитит с автосообщением |
| "Find bugs" / "Найди баги" | Поиск багов — анализирует код и выдаёт список проблем с указанием файл:строка |
| "Add feature" / "Добавь" | Добавление функциональности — читает нужные файлы, пишет новый код |
| "Project overview" / "Расскажи про проект" | Обзор проекта — сканирует структуру проекта, описывает архитектуру |
| "Create and commit" / "Создай и закоммить" | Составная — создание + lint + git add + commit + верификация |
| "Verify file" / "Проверь файл" | Read-only анализ — чтение + lint + подсчёт + поиск TODO + резюме |

### Советы для лучших результатов

1. **Будьте конкретны** — «Добавь валидацию ввода в функцию login в AuthService.kt» работает лучше, чем «исправь код»
2. **Одна задача за раз** — агент лучше справляется с чётко поставленными задачами
3. **Укажите рабочую директорию** — убедитесь, что она указывает на корень вашего проекта
4. **Сначала чтение, потом редактирование** — если хотите изменить файл, назовите его по имени, чтобы агент сначала его прочитал
5. **Проверяйте подтверждения** — всегда просматривайте diff перед тем, как подтвердить запись
6. **Составные команды** — «создай и закоммить» экономит несколько шагов
7. **Маленькая модель?** — Guided Mode включается автоматически, никаких настроек не нужно

## Файлы: просмотр и редактирование

### Файловый менеджер

Файловый менеджер позволяет полноценно управлять файлами, не выходя из приложения.

**Быстрая навигация:**
- **Чип «Home»** — нажмите, чтобы мгновенно вернуться в корень рабочей директории из любой вложенной папки
- **Чип «Downloads»** — нажмите, чтобы перейти прямо в папку «Загрузки» устройства (удобно для переноса моделей или полученных файлов в проект)

**Открытие файлов:**
- Нажмите на файл, чтобы открыть его в редакторе
- Нажмите на папку, чтобы войти в неё
- Git-репозитории отмечены значком «Git» — нажмите, чтобы открыть управление git

**Контекстное меню (долгое нажатие):**
Удерживайте файл или папку, чтобы открыть меню действий:

| Действие | Что делает |
|----------|------------|
| **Копировать** | Помечает файл/папку для копирования |
| **Вырезать** | Помечает файл/папку для перемещения |
| **Переименовать** | Открывает диалог переименования на месте |
| **Удалить** | Удаляет файл или рекурсивно удаляет папку (с подтверждением) |
| **Информация** | Показывает путь, размер и дату изменения |

**Копирование / Вырезание / Вставка:**
1. Удерживайте файл или папку и выберите **Копировать** (или **Вырезать**)
2. Перейдите в целевую директорию
3. Нажмите кнопку **Вставить** (плавающая кнопка внизу экрана)
4. Файл будет скопирован (или перемещён) в текущую директорию

**Создание новой папки:**
- Нажмите кнопку **Новая папка** в панели инструментов
- Введите название и подтвердите — директория создаётся немедленно

### Редактор кода
- Подсветка синтаксиса (на базе Sora Editor + грамматики TextMate)
- Поддержка 30+ языков: Kotlin, Java, Python, JavaScript, TypeScript, C/C++, Go, Rust, Swift и другие
- Поиск и замена
- Нумерация строк
- Автоотступы

## Интеграция с Git

### Настройка Git

1. Перейдите в **Настройки > Учётные данные Git**
2. Введите имя пользователя и Personal Access Token (PAT)
3. Учётные данные шифруются с помощью AES-256 и защищены биометрической аутентификацией

### Возможности Git

На вкладке **Файлы** нажмите значок «Git» на любом репозитории, чтобы открыть экран git:

- **Статус** — просмотр изменённых, подготовленных и неотслеживаемых файлов
- **Diff** — просмотр изменений для каждого изменённого файла
- **Stage/Unstage** — выбор файлов для коммита
- **Commit** — написание сообщения и создание коммита
- **Ветки** — создание, переключение, удаление веток
- **Pull/Push** — синхронизация с удалённым репозиторием
- **Лог** — просмотр истории коммитов

Вы также можете работать с git через **Чат** — просто попросите агента.

### Git через чат

Агент поддерживает продвинутые git-операции:

```
"Покажи подробный git status"   → секции staged, modified, untracked + информация об опережении/отставании
"Автокоммит"                    → автоматически генерирует сообщение коммита из diff
"Запуш на удалённый"            → проверяет опережение/отставание перед push (безопасный push)
"Застэшь изменения"             → сохраняет состояние рабочей директории
"Достань из стэша"              → восстанавливает сохранённые изменения
"Смерджи feature в main"        → объединяет ветки (требует подтверждения)
```

## Настройки

### Настройки модели
- **Выбор модели** — выбор используемой ИИ-модели
- **Загрузка моделей** — просмотр и загрузка моделей из каталога (14 моделей в 4 категориях: Компактные, Код, Универсальные, Мультимодальные)

### Настройки инференса (Авто/Ручной)

У каждого параметра есть переключатель **Auto/Manual**. В режиме Auto система определяет железо устройства и подбирает оптимальные значения.

- **Потоки** — потоки CPU для инференса (Авто: производительные ядра − 1)
- **Размер контекста** — окно токенов (Авто: по RAM и размеру модели, 512–8192)
- **Размер батча** (Расширенный) — обработка промпта (Авто: по RAM, 256–2048)
- **Flash Attention** (Расширенный) — ускорение вычисления внимания (Авто: вкл при ctx ≥ 2048)
- **Зафиксировать в RAM** (Расширенный) — не даёт выгружать модель (Авто: вкл при RAM ≥ 8GB)

### Параметры семплирования (Авто/Ручной, Расширенный режим)

- **Температура** — креативность (Авто: 0.7)
- **Top-P** — ядерная выборка (Авто: 0.95)
- **Top-K** — ограничение K токенами (Авто: 40)
- **Min-P** — фильтрация по вероятности (Авто: 0.05)
- **Штраф за повторы** — штрафует повторения (Авто: 1.1)
- **Окно штрафа** — сколько последних токенов проверять (Авто: 64)

### Ускорение GPU (Расширенный режим)
- **Vulkan GPU** — перенос вычислений на GPU
- **Слои GPU** — количество слоёв на GPU (Авто: по объёму VRAM)

### Настройки агента
- **Рабочая директория** — корневая папка для файловых операций агента
- **Максимум итераций** — количество циклов «думай — действуй — наблюдай» на один запрос (по умолчанию: 15)
- **Конфигурация агента** — расширенные настройки промпта

### Настройки Git
- **Учётные данные Git** — управление вашим PAT для операций push/pull

### Внешний вид
- **Тема** — светлая, тёмная, AMOLED или системная
- **Язык** — английский или русский
- **Кастомные цвета** — баблы пользователя/ассистента, акцент, панель

### О приложении
- **Версия** — текущая версия приложения
- **Лицензии** — используемые библиотеки с открытым исходным кодом
- **Политика конфиденциальности** — как обрабатываются ваши данные
- **Условия использования** — правила использования

## Безопасность

### Что защищено

- **Все файлы остаются на вашем устройстве** — ИИ-модель работает локально, без облачной обработки
- **Учётные данные Git зашифрованы** — AES-256 через Android EncryptedSharedPreferences
- **Биометрическая защита** — отпечаток пальца/лицо/PIN-код для доступа к учётным данным
- **Песочница для путей** — агент не может обращаться к системным директориям (/system, /proc, /dev и т.д.)
- **Подтверждение деструктивных операций** — запись, удаление файлов, git push/merge требуют вашего согласия
- **История файлов** — снимки сохраняются перед каждой записью (доступна отмена)
- **Мягкое удаление** — удалённые файлы попадают в `.sas_trash/`, а не удаляются навсегда

### Что НЕ защищено

- **git push отправляет данные** — при push ваш код отправляется на удалённый сервер, который ВЫ указали
- **ИИ может ошибаться** — всегда проверяйте сгенерированный код перед подтверждением
- **Нет гарантии резервного копирования** — хотя история файлов существует, поддерживайте собственные резервные копии для критически важных данных

## Устранение неполадок

### Агент не отвечает
- Проверьте, что модель скачана и выбрана
- Попробуйте уменьшить максимум итераций в настройках
- Перезапустите приложение

### Модель работает слишком медленно
- Попробуйте модель меньшего размера (3B вместо 7B, или используйте квантизацию Q4_K_M)
- Закройте другие приложения для освобождения оперативной памяти
- Первый ответ всегда медленнее (загрузка модели)
- Для Режима чата универсальные модели (Qwen2.5 3B) быстрее специализированных кодерских

### git push не работает
- Убедитесь, что ваш PAT имеет правильные разрешения (scope: repo)
- Проверьте подключение к сети
