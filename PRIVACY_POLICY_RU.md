# Политика конфиденциальности

**Последнее обновление:** Март 2026

## Общие сведения

CodeAgent («Приложение») — локальный AI-ассистент для разработки на Android. AI-модель работает полностью на вашем устройстве. Приложение не собирает, не передаёт и не хранит персональные данные на внешних серверах.

## Сбор данных

**Мы не собираем никаких персональных данных.** В Приложении нет аналитики, отслеживания, телеметрии или систем отчётов об ошибках.

Все данные, созданные и используемые Приложением, остаются на вашем устройстве, если вы сами не инициируете передачу (см. «Передача данных» ниже).

## AI на устройстве

AI-модель скачивается один раз и работает полностью на вашем устройстве. Ваши запросы, код и диалоги обрабатываются локально и никогда не покидают ваш телефон. Никакие данные не отправляются в облачные AI-сервисы.

## Передача данных по вашей инициативе

Приложение предоставляет интеграцию с git (clone, pull, push, fetch). Когда вы используете эти функции, ваш код и учётные данные git передаются на удалённый сервер, который **вы сами** указываете (GitHub, GitLab, Bitbucket и т.д.). Приложение не контролирует и не отслеживает эти передачи — они идут напрямую с вашего устройства на выбранный вами сервер.

## Доступ к файлам

Приложение запрашивает разрешение `MANAGE_EXTERNAL_STORAGE` для доступа AI-агента к файлам в выбранной вами рабочей директории и каталогу «Загрузки». Это необходимо для основной функциональности: анализа кода, редактирования файлов и работы с внешними файлами. Приложение не сканирует, не индексирует и не передаёт ваши файлы на внешние сервисы.

## Хранение учётных данных

Учётные данные git (Personal Access Token) хранятся на устройстве с использованием `EncryptedSharedPreferences` с шифрованием AES-256. Доступ к учётным данным защищён биометрической аутентификацией (отпечаток пальца, лицо или PIN-код устройства). Учётные данные никогда не передаются, кроме как при аутентификации на указанном вами git-сервере.

## Разрешения

| Разрешение | Назначение |
|---|---|
| `INTERNET` | Git-операции (clone, pull, push, fetch) с удалёнными репозиториями |
| `ACCESS_NETWORK_STATE` | Проверка доступности сети перед git-операциями |
| `MANAGE_EXTERNAL_STORAGE` | Доступ к файлам для AI-агента и каталога «Загрузки» |

## Сторонние сервисы

Приложение не интегрируется со сторонними сервисами аналитики, рекламы или отслеживания. Приложение не содержит рекламы.

## Конфиденциальность детей

Приложение не предназначено для детей младше 13 лет. Мы не собираем данные детей.

## Изменения в политике

Мы можем обновлять эту Политику конфиденциальности. Изменения будут опубликованы в репозитории Приложения с обновлением даты «Последнее обновление».
